# 📊 About the Project

## Automotive Market Analytics

This project is an **end-to-end Business Intelligence and Data Analytics solution** developed to analyze automotive market data and generate meaningful business insights.

The project focuses on:

- Vehicle pricing
- Engine performance
- Fuel efficiency
- Vehicle popularity
- Manufacturer performance
- Vehicle segments
- Vehicle styles
- Transmission types
- Price-performance relationships
- Top-performing vehicles and manufacturers

The objective was not simply to create Power BI visuals, but to demonstrate a complete **data-to-insight workflow** using PostgreSQL, SQL, Power BI, and DAX.

---

# 🎯 Business Problem

Automotive datasets contain large amounts of information about vehicles, pricing, specifications, efficiency, and popularity.

The challenge was to transform this raw information into a structured analytical solution that can answer questions such as:

- Which manufacturers have higher average vehicle prices?
- Which vehicles demonstrate stronger performance?
- How does engine horsepower vary across price segments?
- Which vehicles have better fuel efficiency?
- Which manufacturers and models are most popular?
- Does higher price generally correspond to higher performance?
- Which vehicle categories dominate the market?
- Which vehicles provide a stronger price-performance relationship?
- How do different vehicle sizes and styles compare?

This project addresses these questions through **SQL analysis and interactive Power BI dashboards**.

12. Create interactive filters and slicers

14. Perform Top-N and threshold analysis
15. Analyze price vs. performance
16. Perform scenario analysis
17. Generate business insights
18. Develop conclusions and recommendations
